Seçenek 1: Render.com (Tek Tıkla Otomatik Kurulum) En Kolay • 2 Dakika
Hazırlık Tamam: 342 adet stok ürününüz (Tiandy kameralar, NVR kayıt cihazları, PoE switchler, model kodları) ve 6 adet müşteri PDF'iniz GitHub deponuza (senelcemil3/seneller-pos) otomatik yüklendi!
Nasıl Başlatılır? (Sadece 3 Tık):
  1. Aşağıdaki "Render.com'da Tek Tıkla Başlat" butonuna basın ve GitHub ile Giriş Yap (Sign in with GitHub) deyin (senelcemil3 hesabınız).
  2. Açılan ekranda Blueprint Name kısmına seneller-pos yazıp mavi Apply / Deploy butonuna basın.
  3. 2 dakika içinde size https://seneller-pos.onrender.com adresini verecek. O adresi yukarıdaki kutuya yapıştırıp "Sabit Kapıyı Buluta Bağla" dediğiniz an bilgisayarınızı kapatabilirsiniz!
